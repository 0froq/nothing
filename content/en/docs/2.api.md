## `run()`

Runs void. Takes no arguments and returns `undefined`.

```ts
function run(): void
```

## Options

| Option | Type | Default |
| ------ | ---- | ------- |
| none   | —    | —       |

## Errors

void does not throw. There is no failure path because there is no code path.
